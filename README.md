# AI 개입 실험 분석

건축기사 문항 실험 CSV를 로컬에서 분석하는 Streamlit 서비스입니다.

## 실행

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
.\run_app.ps1
```

브라우저가 열리면 CSV 파일을 업로드합니다. 분석에는 12문항을 모두 완료한 참가자만 포함되며, 이름과 전화번호는 화면과 다운로드 결과에서 제외됩니다.

## 현재 기능

- 전체·범위·직접 입력 방식의 참가순번 선택
- 저지식(1·2학년) / 고지식(3학년 이상)과 Human First / AI First를 조합한 4개 집단 자동 분류
- 네 집단의 표시 여부를 체크해 같은 기준으로 비교
- 성과·수용·유지를 함께 보거나 개별 선택하여 분석
- Human First의 8개 케이스와 의존·불신·고착·수정 분석
- 각 분석의 집단별 비교 그래프
- 의존·불신·고착·수정의 O/X 요약 및 자세히 보기
- 개인정보를 제거한 분석 데이터 다운로드

지표 정의와 화면은 `analysis.py`와 `app.py`로 분리되어 있어 추후 확장할 수 있습니다.
